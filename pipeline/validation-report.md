For each problem, ~5 accepted (AC) and ~5 rejected (WA/TLE) public Codeforces
submissions were fetched (metadata via the official CF API; sources via the
cf-p.vercel.app proxy with a logged-in session) and run locally against the

(CPU time = `timeLimitMs`, no per-language multiplier; wall = 2*TL+2s).
